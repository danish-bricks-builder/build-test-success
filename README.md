# Build, Test, Success: Verification in the Loop Turns LLM Agents into Brick Builders

Code, tasks and recorded results for the paper, presented at the Evaluation of Interactive Agents
workshop at NeurIPS 2026 (Atlanta). Maksym Bondarenko, Independent Researcher.

The release is being assembled from the [Danish Bricks Builder](https://danish-bricks-builder.vercel.app)
codebase: the thirteen tasks, the grader (connection validity, collision, stability, task
requirements), the baseline runner, and the grade records behind every table in the paper.
